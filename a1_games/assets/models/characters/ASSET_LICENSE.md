# Character models

Original low-poly humans generated by `tool/generate_game_models.py`.

Not copied from GTA, PUBG, Fortnite, or any other game. No real-person likenesses.
CC0 for this app.

| File | Use |
| --- | --- |
| human.glb | Idle character select / orbit |
| human-walk-a.glb / human-walk-b.glb | Sidewalk walk cycle |
| human-seat.glb | Driver in the car |
| Textures/*.png | Skin, hair, and suit per driver |
