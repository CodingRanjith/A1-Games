# Character images (cinematic / Unreal-export style)

Place your own **licensed** character PNGs here (transparent background preferred).

| File | Used in |
|------|---------|
| `hero.png` | Home, splash, default games |
| `bird_hunter.png` | Bird Hit |
| `bubble_shooter.png` | Bubble Shooter |
| `movie_host.png` | Movie Finder |
| `target_hunter.png` | Target Hit |

## Using Unreal Engine exports

1. In Unreal, set up a clean character render (transparent or solid BG).
2. Export PNG / high-quality screenshot.
3. Replace the matching file above (same filename).
4. Run `flutter pub get` / hot restart.

**Important:** Do not ship Epic/Fortnite copyrighted characters unless you have a commercial license. The bundled images are original placeholders for the app.
